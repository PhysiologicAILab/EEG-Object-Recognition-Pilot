# Analysis code guide

- `preprocessing/`: final cohort EEG preprocessing and NPZ-to-MNE loader.
- `qc/`: final cohort QC, ocular-detector validation, retained-epoch lateral-eye QC, and supplementary ICA diagnostic.
- `spectral_analysis/`: final spectral-feature extraction and absolute-power analysis.
- `statistics/`: final ROI statistics and dissertation EEG summary generation.
- `behavioural_speech_analysis/`: WAV inventory, constrained speech analysis, manual-label integration, and final behavioural results.
- `stimulus_analysis/`: low-level visual-feature analysis of the formal image pairs.
